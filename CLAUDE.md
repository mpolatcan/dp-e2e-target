# CLAUDE.md — dp-e2e-target

A small utility repository. Everything ships from `src/`, and `src/exports.generated.mjs` is
generated by `scripts/gen-exports.mjs` — never edit it by hand.

## Conventions

- Tests use `node:test` with `node:assert/strict`. Each source module has its own test file;
  cross-cutting contract files that apply to several helpers are the exception.
- Helpers are pure functions with no I/O.
- `src/` must contain no tab characters — `scripts/lint.mjs` and the CI changed-files lint fail on them.
- Run `node scripts/gen-exports.mjs`, then `node scripts/lint.mjs`, `npm run build` and
  `node --test test/*.test.mjs` before committing.

## Learnings

- Add new exported helpers to `src/slugify.mjs` (export beside `slugify`), not a new `src/*.mjs` module — `scripts/gen-exports.mjs`, `npm run build`, and `test/exports.test.mjs` are all hard-wired to that single file, so a helper placed elsewhere escapes export-list generation and the build check.
